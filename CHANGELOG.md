## [v0.1.0] — 2026-11-05

### ✨ Новые функции
- **Инициализация форка Terrarich**: создание форка проекта Horizon (переписанный на Rust Minecraft Java Edition 26.3).
- **Система правил репозитория (`RULES.md`)**:
  - Полный свод правил по защите авторских прав и лицензированию (MIT, запрет проприетарных ресурсов Mojang).
  - Требования к атомарности и качеству коммитов (Conventional Commits, запрет WIP-коммитов).
  - Закрепление авторства форка за **Terrarich**.
- **Автоматизированная валидация коммитов**:
  - Скрипт `tools/check_commit_msg.py` и Git hook `.githooks/commit-msg` для контроля понятных названий коммитов.
- **Инструменты генерации ченджлогов и релизов**:
  - Скрипт `tools/terrarich_changelog.py` для автоматического извлечения коммитов и форматирования заметок к релизам.
  - Интерактивная утилита релиза `tools/terrarich_release.py` и PowerShell-скрипт `tools/terrarich_release.ps1` для безопасной публикации релизов только по явной команде пользователя.
- **Ручной GitHub Actions Workflow**:
  - Создан процесс `.github/workflows/terrarich-release.yml` с поддержкой `workflow_dispatch` (запуск релиза по нажатию кнопки).

### 🛡️ Безопасность и Лицензии
- Обновлён файл `LICENSE` с включением авторских прав Terrarich на модификации и форк при полном сохранении оригинальной лицензии MIT и уведомлений третьих лиц (`THIRD_PARTY_NOTICES.md`).
- Активирован локальный хук защиты от случайного добавления файлов игры Mojang (`tools/check_public_tree.py`).
- Отключена спонтанная автоматическая публикация ночных сборок по расписанию для полного контроля над релизами.
